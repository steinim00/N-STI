# Ashlar

Geometric sans-serif typeface in nine weights (Thin to Ultra) with italics, 18 styles in total.
Latin script with extended coverage (Icelandic, Faroese, Sami, Turkish, Maltese and more).

- `TTF/` hinted TrueType, for Windows, Word and general installation
- `OTF/` CFF OpenType, for Adobe apps and Figma
- `WOFF2/` for the web

OpenType features: liga, tnum, pnum, zero, sups, subs, sinf, numr, dnom, frac, ordn, case, cpsp, kern, mark, mkmk.

Status: work in progress. The italics are obliques built from skewed outlines, and there is no variable font yet.
No licence has been chosen yet.
